## Christian Okeke

Co-founder and CTO of **Novapath Technologies**, building **TRY**, keke ride-hailing for Nigerian cities.

TRY lets riders book a keke with a verified driver, see the fare before the trip, and pay by wallet or cash. Drivers get trip offers nearby and withdraw their earnings to their bank. The rider app is on the App Store and Google Play.

**What I build with:** TypeScript, NestJS, PostgreSQL, Redis, React Native (Expo), Docker, GitHub Actions
